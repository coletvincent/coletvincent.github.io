A Brief Introduction to Manifolds

What is a manifold?

A manifold can be thought of as a shape of any dimension, though you can really only visualize them in the 3D sense. These shapes have to adhere by specific rules, and can also inherit special properties that make them very, very useful in a lot of broad topics. I'll talk about what makes some of these properties desirable later on. For now, we can talk about the rigorous definition of a manifold. A manifold is an \(n\text{-dimensional}\) structure that is locally Euclidean. But what does it mean to be locally Euclidean?

To be locally Euclidean means that for each point that can be defined on the manifold, we can also define a tangent plane in which we can treat the space as Euclidean. Since a tanget plane is unique to the point in which it is tangent to, it should be natural to understand what we mean when we say locally Euclidean.
